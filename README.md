# One Star for Monday

Entry for the make.fun bounty
[One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61).

## The line

> One star. The menu lists Friday under dessert, four days away, and the waiter already charged me for it.

19 words, 104 characters. One line, plain text, no explanation.

## Why this angle wins

The field is saturated with three devices: cold coffee, a waiter who took or billed the weekend, and "ordered the weekend, got Monday instead" — each repeated dozens of times. This line uses a device nobody in the field touches: the menu itself, which lists Friday under dessert. The joke is Monday-specific by counting — only Monday sits four days from Friday — and it still reads as a genuine diner's complaint: menu, waiter, and a bill that charges in advance for something four days away. At 19 words it retypes without trimming.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), fails
loudly if the line ever leaves the 1–180 character or 25-word gate, and
exits 0. No network, no randomness, no clock — the output is identical
on every run.
